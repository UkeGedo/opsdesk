# Auditoría de OpsDesk — 8 de noviembre de 2026

## Alcance y prioridades

Revisión focalizada del código de API, permisos, sesiones, adjuntos, copias, configuración, archivos destinados a GitHub y navegación de clientes. Se ejecutaron las verificaciones indicadas más abajo. Es una revisión de ingeniería, no una prueba de penetración ni una evaluación independiente de accesibilidad.

## Verificación

La ejecución local produjo 39 pruebas de API aprobadas y 85,97 % de líneas en ocho módulos críticos seleccionados. Pasaron la prueba de rotación, lint, tipos, formato, compilación y 11 recorridos de navegador contra datos aislados; estos incluyen la nueva paginación. La auditoría de dependencias de producción no encontró vulnerabilidades conocidas en el momento de la consulta. El flujo alojado de GitHub Actions aún no se ha verificado.

La comprobación de secretos examinó 144 archivos no ignorados con patrones de tokens GitHub, claves privadas, claves AWS y JWT. No hubo coincidencias. No examina todas las formas posibles de credenciales o datos personales. Los datos de demostración y cuentas `example.test` son ficticios; los directorios de datos y credenciales de entorno no se incluyen.

Los procedimientos y riesgos restantes están en [evaluación](evaluation.md), [seguridad](security-asvs.md), [despliegue](deployment.md) y [copias](backups.md). No se afirma conformidad ASVS ni un despliegue público verificado.
