# Arquitectura de información y flujos

Público: presentación → capacidades → enfoque → fundamentos. Futuro: acceso → panel → clientes / tickets / tareas / inventario / notificaciones / reportes / administración / perfil. Administrador ve todos los módulos autorizados; supervisor coordinación y reportes; técnico asignaciones y actividad; cliente sus tickets y perfil. Los enlaces no sustituyen autorización.

Flujo previsto: cliente crea ticket → supervisor asigna → técnico registra actividad y solución → cliente consulta historial. En cada paso se valida permiso y se comunica el resultado.

Wireframe escritorio (previsto):

```text
[marca] [búsqueda]                         [perfil]
[menú] | título y acción principal
       | filtros
       | tabla / contenido y estado
```

Móvil 360 px:

```text
[marca]                     [menú]
[título]
[acción principal]
[filtros]
[lista de registros]
```

Los wireframes son especificaciones, no pantallas funcionales de esta fase.
