# Sistema de diseño

Marca: OpsDesk comunica orden y confianza; el isotipo combina tres módulos que forman una estructura conectada. La marca actual está implementada mediante CSS reproducible; se requiere exportar SVG antes de utilizarla fuera de la interfaz.

Tokens: azul #142338, petróleo #167D78, fondo #F7F8FA, blanco #FFFFFF, texto #192638, secundario #64748B, aviso #C58A35, error #C84D56. DM Sans para interfaz y Plus Jakarta Sans para títulos, con sans-serif de respaldo. Escala base 4/8/12/16/24/32/48/64; radios 4/6/8; sombras suaves y bordes #DFE5E7. Iconos Lucide con texto accesible.

Botones primarios sólidos, secundarios de texto; hover y foco visible; deshabilitado y carga se incorporarán junto con formularios reales. Campos futuros tendrán etiqueta persistente, ayuda y error asociado por aria-describedby. Navegación por rol y tablas con encabezados, filtros, paginación y estado vacío se implementarán con sus flujos. Mensajes deben indicar acción y resultado sin depender solo del color. A 360 px se apilan columnas, se oculta navegación de anclas y se conserva acceso al contenido. El tema se guarda localmente. Revisar contraste y WCAG 2.2 AA con herramientas y pruebas manuales antes de declarar conformidad.

Ejemplos reales: botones «Explorar OpsDesk» y «Conoce el enfoque», tarjetas de capacidades y navegación por anclas en la página pública. No representan acciones operativas.
